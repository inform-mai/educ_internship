# Извлечение связей (Relation Extraction)

Этот модуль отвечает за превращение пар сущностей в осмысленные факты (триплеты) для графа знаний Memgraph. 

## Установка

```
pip install -r requirements.txt
```

## Использование

1.  Убедитесь, что запущен локальный сервер vLLM на порту 8010:
    ```bash
    docker run --gpus all -p 8010:8010 vllm/vllm-openai:latest ...
    ```
2.  Установите зависимости проекта:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите скрипт извлечения:
    ```bash
    python relation_extractor.py
    ```

## Кратко о модуле

Модуль работает по принципу Schema-based Relation Extraction с LLM-валидацией:

1.  Генерация пар: Для каждого чанка текста создаются все возможные уникальные пары (Субъект, Объект) из предварительно выделенных сущностей.
2.  LLM-валидатор: Каждая пара отправляется в локальную модель (vLLM) с жестким промптом. Модель должна определить наличие связи из заранее заданной онтологии.
3.  Structured Output: Ответ модели строго ограничен JSON-схемой (`json_object`), что исключает ошибки парсинга и гарантирует машиночитаемый формат.

Онтология связей
На текущий момент поддерживаются следующие типы отношений:
*   `RUNS_ON` — работает на
*   `STORES` — хранит
*   `IS_PART_OF` — компонент является частью системы
*   `CREATED_BY` — создан
*   `NONE` — явная связь между сущностями отсутствует (фильтр ложных срабатываний).


## Тесты

**test.txt** - обычный текст про Пушкина.

Парсинг:
```python
from parser import parse_file
text = parse_file("test.txt")
```
На выходе - строка с текстом, 593 символа.

Чанкинг:
```python
from chunker import split_text
chunks = split_text(text, chunk_size=200, overlap=50, source="test.txt")
```
На выходе - несколько чанков по 200 символов, с перекрытием в 50 символов между соседними.

---

**test_table.pdf** - pdf с текстом и таблицей (поэты, годы рождения, города).

Парсинг:
```python
text = parse_file("test_table.pdf")
```
На выходе - текст со страницы плюс отдельно та же таблица, но в формате markdown:
```
| Имя | Год рождения | Город |
| --- | --- | --- |
| Пушкин | 1799 | Москва |
```

---

**docx файлы** - поддерживаются так же, как txt и pdf. Картинки в docx не обрабатываются, берётся только текст и таблицы (тоже переводятся в markdown).
