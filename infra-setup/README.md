#  Инфраструктура для проекта "Граф знаний"

Настройка Docker-окружения с vLLM, Qdrant и Memgraph для проекта по формированию графа знаний из неструктурированного текста.

##  Что это такое

Этот репозиторий содержит **инфраструктурную часть** проекта: три сервиса, которые работают вместе, чтобы обрабатывать текст и строить граф знаний.

- **vLLM** — локальный сервер для запуска языковой модели (Gemma 4)

- **Qdrant** — векторная база данных для семантического поиска

- **Memgraph** — графовая база данных для хранения связей между сущностями

##  Быстрый старт

### Шаг 1: Требования

Перед началом убедись, что у тебя установлено:

- ✅ **Docker Desktop** (последняя версия) — [скачать здесь](https://www.docker.com/products/docker-desktop/)

- ✅ **Python 3.10+** (для тестового скрипта)

### Шаг 2: Установка


# Клонируем репозиторий

git clone <URL_РЕПОЗИТОРИЯ>

cd infra-setup

# Создаём виртуальное окружение (опционально, но рекомендуется)

python -m venv .venv

# Активируем виртуальное окружение

# Windows:

.venv\Scripts\activate

# macOS/Linux:

source .venv/bin/activate

# Устанавливаем зависимости Python

pip install -r requirements.txt

# Запускаем все три сервиса
docker-compose up

# Шаг 5: Проверка работы
python test_infra.py

Если всё работает, то увидишь:
- vllm is working
- qdrant is working
- Memgraph is working (with driver neo4j)

# Шаг 6: Остановка сервисов

 В терминале, где запущен docker-compose, нажми Ctrl+C
### Или в другом терминале:
docker-compose down
